# sfumato: бэклог

Замечания из ревью (tech lead, art director, куратор). Вернуться после срезов 0-2.

## Tech
- [ ] Web Worker для MediaPipe, если fps < 30 (ImageBitmap, один кадр «в полёте»)
- [ ] Адаптивное качество: меньше слов и слабее дымка при просадке fps
- [ ] Рендер во внутреннем 720x1280 и апскейл при экспорте, если запись 1080x1920 тормозит
- [ ] Проверить `ctx.filter` в Safari; запасной вариант уже даунскейл-дымка
- [ ] Конвертация WebM в MP4: `ffmpeg -i in.webm -c:v libx264 -pix_fmt yuv420p out.mp4`
- [ ] Лицензия Strudel (AGPL?), запасной вариант Tone.js
- [ ] Fallback без камеры и при отказе в доступе (режим мыши уже есть)

## Art direction
- [ ] Два героя: лупы и созвездие слов; остальное фоном
- [ ] `screen` с ограниченной альфой вместо `lighter`, видео темнее на 40-60%, подложка под подписи
- [ ] Палитра 6-7 тонов в OKLCH с одинаковой светлотой; оранжевый, чернильный, кремовый + холодный голубой для рук
- [ ] Три уровня подписей, IBM Plex Mono, слова по-русски, название `sfumato` латиницей
- [ ] Медленное движение с инерцией, слабое зерно
- [ ] Сторибоард видео 20-30 с: название, слова, руки и сцены, рука ближе, финальная карточка; первый кадр как обложка; видеоряд работает без звука

## Концепт: ощущения как поэзия
- [ ] Список слов: от тем к чувственным фрагментам («запах мокрой штукатурки», «щелчок выключателя»)
- [ ] «Сложилось»: сейчас строка из деталей через пробел; позже авторские строки или шаблон «и вдруг...»
- [ ] Звук на «сложилось» (аккорд), срез 4
- [ ] Порядок рук при скрещивании: указатели могут перескакивать между слотами
