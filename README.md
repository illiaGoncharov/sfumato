# sfumato

Интерактивный скетч на стыке вебкамеры и генеративной типографики: фигура в размытой дымке (*sfumato*), вокруг дрейфуют слова-ощущения в цветовом пространстве OKLCH. Жесты рук собирают созвучные фрагменты — на мгновение складывается строка, потом снова распад. Камера и трекинг рук работают **только в браузере**, видео на сервер не отправляется.

**Демо:** https://illiaGoncharov.github.io/sfumato/

Chrome на ноутбуке. `C` — камера, `V` — 9:16, `H` — скрыть кнопки. На Mac в меню камеры выключи «Фон» и «Портрет».

Восстановить `vendor/` после клона: `./setup.sh`
